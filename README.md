# cgwork2 · 三维层级场景：太阳系

AP2：太阳–地球–月球三级层级场景，含三个扩展（完整太阳系、日月食视点、虚拟轨迹球）。原生 WebGL 2.0 + 教材配套库（`Common/initShaders.js`、`Common/MV.js`）。

## 文件

```
cgwork2/
├── index.html        页面、着色器、样式
├── src/
│   ├── main.js       初始化、层级模型矩阵、渲染循环

│   ├── camera.js     相机：拖拽、漫游、双投影、轨迹球、视点
│   └── ui.js         参数面板
└── textures/         8 张位图贴图
```


## 层级结构

模型矩阵逐层相乘，`mult(a, b)` 表示 b 先作用于顶点：

```
场景原点（太阳）
├── 太阳      Ry(自转) · S
└── 行星公转系 ×6  Ry(公转) · T(距离)       ← 水金地火木土，循环生成
    ├── 行星    [Rz(23.5°)·] Ry(自转) · S   ← 地球先倾斜自转轴，再挂公转系
    ├── 月球轨道系  handRotX(5.1°)          ← 手造矩阵，不继承地轴倾角（仅地球下）
    │   └── 月球  Ry(公转) · T(1.1) · Ry(自转) · S
    └── 土星环  S（内径 1.25、外径 2.1 倍半径，仅土星下）
```

所有天体共用同一个单位球网格（3185 顶点），大小全靠模型矩阵缩放；参数全在 `planets.js` 的 `BODIES` 表里。

地轴倾角的关键是顺序：先 `Rz(23.5°)` 把倾斜地球的轴，外层再叠公转。反过来先公转再倾斜，轴会跟着公转转动，就不再始终指向一个方向。面板把倾角拖成 0 能直接看出差别。

## 手造矩阵

月球轨道面绕 X 轴倾 5.1° 的矩阵（`main.js` 的 `handRotX`）是将公式手工填进 4x4：

```
y' = c·y - s·z      ⎡1  0   0  0⎤
z' = s·y + c·z  →   ⎢0  c  -s  0⎥   c = cos5.1°, s = sin5.1°
                    ⎢0  s   c  0⎥
                    ⎣0  0   0  1⎦
```

MV.js 按行主序书写（`mat4(...)` 每四个数一行），`flatten()` 上传时转列主序，验证过与库中 `rotateX` 结果一致。

## 纹理

太阳、六大行星、月球各一张位图（2720×1360 等距柱状展开）。经纬球每个顶点带 UV（u 沿经度、v 沿纬度，v=1 在北极），`texImage2D` 上传后由片元着色器采样。

上下颠倒：图片首行在顶部，WebGL 的 v=0 在底部，若不处理则南极会被贴到北极。这里用 `gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, true)` 上传时翻转。

光照是最简漫反射（面向太阳亮、背面暗），太阳自身发光不参与光照。

## 双投影

`O` 键切换透视 / 正交。正交的视野高度按相机距离换算，切换时画面大小基本一致：

- 透视：近大远小，轨道圆靠近相机一侧明显更大；
- 正交：无近大远小，大小只取决于实际半径，平行轨道线处处平行。

对比截图：`docs/screenshot-perspective.png`、`docs/screenshot-ortho.png`。

## 相机漫游

默认静态视角，空格或面板"漫游"按钮开关漫游。路径为 5 个关键帧（方位角绕场一周，高度与距离变化），smoothstep 插值，24 秒一圈。

漫游与手动随时接管：拖动或滚轮立刻暂停漫游；再按空格从当前视角平滑过渡回路径（1.2 秒，方位角沿路径单调，直接反推接续点，不会跳回起点）。

## E1 完整太阳系

六颗行星挂在各自公转系下循环生成，参数全部集中在 `BODIES` 表。

- **土星环**：XZ 平面圆环（1.25–2.1 倍行星半径），法线朝 +Y，u 沿径向。贴图为程序化 256×1 canvas 条纹（含卡西尼缝，alpha 渐变），半透明混合且不写深度，避免环前后两半互相遮挡。
- **小行星带**：火星与木星之间（6.3–7.5）2500 个随机点，`gl.POINTS` 绘制，整体绕 Y 慢转。

## E2 日食 / 月食视点

面板"视点"分段切换：

- **地面观日**：相机贴地球向阳面表面，看向太阳，月球转到日地之间时遮住太阳 —— 日食；
- **月球观地**：相机贴月球向地面表面，看向地球，月球进入地球背光侧时被地球挡住阳光 —— 月食。

食是纯几何遮挡：月球轨道倾角 5.1° 远小于日、月视角半径之和，每圈（默认约 1.9 秒）有两次食窗口。

每帧从模型矩阵平移列取地球 / 月球世界坐标写入 `cam.anchors`，视点模式用这两个锚点构造 `lookAt`。

## E3 虚拟轨迹球

面板"轨迹球"开关切换拖拽方式：

1. 屏幕坐标投影到半球面：`z = sqrt(1 - x² - y²)`，球外 z=0；
2. 前后两点的叉积给出旋转轴，`asin(|axis|)` 给出角度；
3. 轴经相机基（右 / 上 / 指向相机）变换到世界系，用 `rotate(angle, axis)` 同时旋转视线与 up；
4. 视线反解回方位角 / 仰角，滚转留在 up 里。

与普通拖拽的区别：普通拖拽方位角、仰角解耦且 up 恒竖直；轨迹球绕垂直于拖拽方向的轴转，带滚转。

## 操作

| 操作 | 效果 |
|---|---|
| 左键拖动 | 旋转视角（接管漫游；轨迹球开启时走轨迹球） |
| 滚轮 | 缩放（接管漫游） |
| O | 切换透视 / 正交 |
| 空格 | 暂停 / 继续漫游 |
| 面板滑条 | 公转速度、自转速度、轴倾角 |
| 面板按钮 | 轨道线、视点、轨迹球、投影、漫游 |
